02 / The boundary

Know what’s checked.

Read the threat model ↗

Package inspection

Stage a package, inspect its source and supply-chain evidence, then review the cited findings. Normal static scans do not execute the inspected package’s code or install scripts.

Coverage varies

npm gets behavioral and supply-chain checks. PyPI has narrower coverage; general Python behavioral analysis is not implemented. Dependency checks depend on the command and flags you use.

Runtime has limits

Static analysis cannot see runtime-fetched payloads. Listing MCP tools can start a server; the proxy runs it, and opt-in canary scans execute code in a sandbox.

Submitted source is processed on Cloudflare. Do not send secrets. Source checks accept up to 16 files and 16 KiB total; rate limits apply. Package names and versions are sent to npm and OSV for metadata checks.
